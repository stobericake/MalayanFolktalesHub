# 📖 MalayanFolktalesHub: Interactive Cultural Folklore Platform

An interactive web-based application developed as part of **CSC577 - Software Engineering**, designed to preserve, explore, and share traditional Malay folklore through community engagement and digital storytelling.

---

## 🚀 Overview
MalayanFolktalesHub offers a rich, immersive experience for readers passionate about traditional tales. The platform combines a curated digital repository of folklore with modern interactive social features, allowing users to discover top-rated stories, explore regional narratives, and connect over a shared cultural heritage.

---

## 🛠️ Tech Stack & Architecture
* **Frontend:** HTML, CSS, JavaScript, Responsive UI Components
* **Backend & Logic:** PHP / Dynamic Scripting
* **Database Management:** MySQL / Relational Database
* **Architecture & Tools:** MVC (Model-View-Controller) design patterns, Version Control via Git

---

## ✨ Key Features & User Journey
* **"Most Ranking" Spotlight:** Highlights top-rated and community-favorite stories for immediate discovery upon arrival.
* **Advanced Multi-Criteria Filtering:** Allows users to refine searches by specific themes, cultural significance, or geographical region.
* **Community Engagement & Feedback:** Supports story ratings, comments, interpretation sharing, and social bookmarking to build a personalized reading collection.
* **Interactive Reading Hub:** Fosters a collaborative, community-driven environment where readers can bond over cultural heritage.
